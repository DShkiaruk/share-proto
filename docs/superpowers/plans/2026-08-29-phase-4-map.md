# share-proto v2 — Phase 4 (Map) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A map of the prototype — every screen as a thumbnail with its comment counts, arrows for the clicks that connect them — opened with **M**, clickable (a node takes you to that screen), editable by the designer (rename, hide), and filled automatically by a crawler the agent runs after deploy.

**Architecture:** The learned navigation graph (`state.nav`) already *is* the map's structure; Phase 4 adds pictures and a viewer. Screen shots are private blobs `shots/<key>/<ts>.jpg` (key = base64url of the label), indexed by `shotlog/` events into `state.shots {label → pathname}`; a thread preview doubles as a shot when a screen has none. `mapmeta/` events hold designer aliases and hidden nodes. The crawler (`scripts/crawl.mjs`, Playwright on the designer's machine) logs in, walks screens breadth-first with **real mouse clicks** — so the overlay itself learns the edges — and posts a shot per new label through the same session. The map panel lives in the overlay's shadow root, laid out in BFS layers from the boot screen, with pan/zoom, and reuses `autoNavigate`'s hop logic via a new `navigateToLabel()`.

**Tech Stack:** vanilla JS + inline SVG (no graph library), Node ≥ 18, Playwright 1.62 (devDependency, crawler), `node:test`.

**Spec:** `docs/superpowers/specs/2026-08-29-share-proto-v2-design.md` — §7.5, §8.3, §9, §5.6 (labels), §15.3.

## Global Constraints

- `shot`, `mapmeta` writes are designer-only, server-enforced; shots are readable by any signed-in role (spec §4.5).
- Client sees counts for their own threads only (the GET filter already does this).
- Crawler never clicks destructive controls: text matching `/delete|remove|reset|sign out|log out|logout|clear|discard/i` is skipped; every branch starts from a reload; 5-minute wall clock and `--max-screens` cap (spec §9).
- Crawler clicks are real (`page.mouse.click`), never `el.click()` — the overlay must learn the edges the way it learns from humans.
- Map images go through `/api/file` (private store); no graph library; `/map.html` deferred (spec §15.3).
- Branch `v2`, push after the phase.

```js
export const labelKey = (label) =>
  Buffer.from(String(label), 'utf8').toString('base64').replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '').slice(0, 80) || '_';
export const applyShot = (shots, ev) => (ev && typeof ev.label === 'string' && typeof ev.path === 'string' ? { ...(shots || {}), [ev.label]: ev.path } : shots || {});
export function applyMapMeta(meta, ev) {
  const m = { aliases: { ...(meta?.aliases || {}) }, hidden: [...(meta?.hidden || [])] };
  if (!ev) return m;
  if (ev.alias && typeof ev.alias.label === 'string') {
    const name = String(ev.alias.name || '').trim().slice(0, 60);
    if (name) m.aliases[ev.alias.label] = name; else delete m.aliases[ev.alias.label];
  }
  if (typeof ev.hide === 'string' && !m.hidden.includes(ev.hide)) m.hidden.push(ev.hide);
  if (typeof ev.show === 'string') m.hidden = m.hidden.filter((l) => l !== ev.show);
  return m;
}
```

### Task 2: Crawler — `scripts/crawl.mjs`

**Files:** `scripts/crawl.mjs`, `package.json` (script `"crawl": "node scripts/crawl.mjs"`).

**Interfaces:** `node scripts/crawl.mjs <url> --password <team> [--name Crawler] [--depth 4] [--max-screens 60] [--viewport 1280x800] [--headed]` → prints a summary `{screens, edges, shots, seconds}` and exits 0; non-zero on login failure.

- [ ] **Step 1: Write it**
```js
#!/usr/bin/env node
// Walk a share-proto deployment breadth-first with real mouse clicks so the
// overlay learns the navigation graph, and post a screenshot per screen for
// the map. Runs on the designer's machine (Playwright is a dev dependency of
// the skill repo, not of the template).
import { chromium } from '@playwright/test';

const args = process.argv.slice(2);
const url = args.find((a) => !a.startsWith('--'));
const opt = (k, d) => { const i = args.indexOf(`--${k}`); return i >= 0 ? args[i + 1] : d; };
if (!url || !opt('password')) { console.error('usage: crawl.mjs <url> --password <team-password> [--depth 4] [--max-screens 60] [--viewport 1280x800] [--name Crawler] [--headed]'); process.exit(2); }
const DEPTH = Number(opt('depth', 4)), MAX = Number(opt('max-screens', 60));
const [W, H] = opt('viewport', '1280x800').split('x').map(Number);
const SKIP = /delete|remove|reset|sign out|log out|logout|clear|discard/i;
const t0 = Date.now(); const budget = () => Date.now() - t0 < 5 * 60 * 1000;

const browser = await chromium.launch({ headless: !args.includes('--headed') });
const page = await browser.newPage({ viewport: { width: W, height: H } });
await page.goto(url);
await page.getByLabel('Your name').fill(opt('name', 'Crawler'));
await page.getByLabel('Password').fill(opt('password'));
await page.getByRole('button', { name: 'Continue' }).click();
await page.waitForSelector('[data-fp-host]', { timeout: 20000 }).catch(() => { console.error('login failed'); process.exit(1); });
const label = () => page.evaluate(() => window.__fp?.label() || document.title);
const settle = (ms = 1200) => page.waitForTimeout(ms);

// Visible, clickable, non-destructive controls outside the overlay, as anchors {path, txt, x, y}.
const controls = () => page.evaluate(() => {
  const host = document.querySelector('[data-fp-host]');
  const out = [];
  for (const el of document.querySelectorAll('button, a, [role="button"], [role="tab"], [role="menuitem"], summary')) {
    if (host && (el === host || host.contains(el))) continue;
    const r = el.getBoundingClientRect();
    if (r.width < 4 || r.height < 4 || r.bottom < 0 || r.top > innerHeight || r.right < 0 || r.left > innerWidth) continue;
    const cs = getComputedStyle(el);
    if (cs.visibility === 'hidden' || cs.pointerEvents === 'none' || el.disabled) continue;
    const txt = (el.textContent || el.getAttribute('aria-label') || '').replace(/\s+/g, ' ').trim().slice(0, 60);
    out.push({ txt, x: r.left + r.width / 2, y: r.top + r.height / 2 });
  }
  return out;
});
const shoot = async (lbl) => {
  const buf = await page.screenshot({ type: 'jpeg', quality: 80 });
  const ok = await page.evaluate(async ([l, b64]) => (await fetch('/api/comments', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ action: 'shot', label: l, image: 'data:image/jpeg;base64,' + b64 }) })).ok, [lbl, buf.toString('base64')]);
  return ok;
};
// A path is the list of control texts+positions clicked from the boot screen.
const replay = async (path) => {
  await page.goto(url); await page.waitForSelector('[data-fp-host]'); await settle();
  for (const step of path) {
    const cs = await controls();
    const hit = cs.find((c) => c.txt === step.txt) || cs.find((c) => Math.hypot(c.x - step.x, c.y - step.y) < 8);
    if (!hit) return false;
    await page.mouse.click(hit.x, hit.y); await settle();
  }
  return true;
};

const seen = new Map(); // label → path
const queue = [[]];
let edges = 0, shots = 0;
await settle();
seen.set(await label(), []);
if (await shoot([...seen.keys()][0])) shots++;
while (queue.length && seen.size < MAX && budget()) {
  const path = queue.shift();
  if (path.length >= DEPTH) continue;
  if (!(await replay(path))) continue;
  const from = await label();
  const cs = (await controls()).filter((c) => c.txt && !SKIP.test(c.txt));
  const tried = new Set();
  for (const c of cs) {
    if (!budget() || seen.size >= MAX) break;
    if (tried.has(c.txt)) continue; tried.add(c.txt);
    if (!(await replay(path))) break;
    await page.mouse.click(c.x, c.y); await settle(1500);
    const to = await label();
    if (to !== from && !seen.has(to)) {
      seen.set(to, [...path, c]); queue.push([...path, c]); edges++;
      if (await shoot(to)) shots++;
      console.log(`  ${from} → ${to}  via "${c.txt}"`);
    }
  }
}
console.log(JSON.stringify({ screens: seen.size, edges, shots, seconds: Math.round((Date.now() - t0) / 1000) }));
await browser.close();
```
(The overlay records the edge itself when a trusted click changes the label — the crawler only counts them.)

```js
  function mapModel() {
    const hidden = new Set(state.mapmeta?.hidden || []);
    const alias = state.mapmeta?.aliases || {};
    const nodes = new Set();
    const edges = [];
    for (const [key, anchor] of Object.entries(state.nav)) { const [a, b] = key.split('>'); if (isFallbackLabel(a) || isFallbackLabel(b)) continue; nodes.add(a); nodes.add(b); edges.push({ from: a, to: b, txt: anchor?.txt || '' }); }
    for (const t of state.threads) if (t.screenLabel && !isFallbackLabel(t.screenLabel)) nodes.add(t.screenLabel);
    for (const l of Object.keys(state.shots || {})) nodes.add(l);
    const start = bootScreen && nodes.has(bootScreen) ? bootScreen : [...nodes][0];
    // BFS layers from the start; unreachable nodes go to the last layer.
    const depth = new Map([[start, 0]]);
    const q = [start];
    while (q.length) { const c = q.shift(); for (const e of edges) if (e.from === c && !depth.has(e.to)) { depth.set(e.to, depth.get(c) + 1); q.push(e.to); } }
    const maxD = Math.max(0, ...depth.values());
    const list = [...nodes].filter((n) => !hidden.has(n)).map((label) => ({ label, name: alias[label] || label, d: depth.has(label) ? depth.get(label) : maxD + 1, shot: (state.shots || {})[label] || null, open: state.threads.filter((t) => t.screenLabel === label && !t.resolved).length, total: state.threads.filter((t) => t.screenLabel === label).length }));
    const cols = new Map();
    for (const n of list) { if (!cols.has(n.d)) cols.set(n.d, []); n.row = cols.get(n.d).length; cols.get(n.d).push(n); }
    return { nodes: list, edges: edges.filter((e) => !hidden.has(e.from) && !hidden.has(e.to)), hidden: [...hidden] };
  }
```
